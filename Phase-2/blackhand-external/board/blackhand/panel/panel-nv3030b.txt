# NV3030B init sequence — FALLBACK for the Waveshare 1.83" panel.
#
# Use this ONLY if the panel stays dark with panel.txt while SPI is confirmed
# transmitting (see §7.2 of the bring-up brief). Switch with use-panel.sh.
#
# Transcribed from LCD_1IN83_InitReg() in the Waveshare vendor demo ZIP. The
# 0x61-0x68 and 0xE0-0xEc banks have no ST7789 equivalent; the two sequences
# are NOT interchangeable.
#
# Format is identical to panel.txt (see mkpanelbin.py). Hardware reset, window
# addressing and backlight are the driver's job — not duplicated here.
