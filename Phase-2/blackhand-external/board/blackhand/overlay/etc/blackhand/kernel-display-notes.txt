Kernel display checklist

This file documents kernel configuration required for HyperPixel bring-up.

Required kernel config
- CONFIG_DRM=y
- CONFIG_DRM_VC4=y
- CONFIG_DRM_VC4_KMS=y
- CONFIG_DRM_FBDEV_EMULATION=y
- CONFIG_FB=y
- CONFIG_I2C_GPIO=y
- CONFIG_INPUT_TOUCHSCREEN=y
- CONFIG_TOUCHSCREEN_GOODIX=y

Verify after boot
- /dev/dri/card0 exists
- /dev/fb0 exists
- dmesg shows vc4 and dpi entries
